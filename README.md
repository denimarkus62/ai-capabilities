# База знаний: что умеет Claude

Дашборд для команды. Два раздела: профессии и сервисы. Для каждой профессии собраны задачи, которые Claude делает сам, через API, коннекторы и MCP, и те, что остаются за человеком. Для каждого сервиса (Telegram, YouTube, 1С, Wildberries и других) указано, как Claude с ним работает и что для этого нужно. Каждая задача оценена по 10-балльной шкале.

Сайт: https://denimarkus62.github.io/ai-capabilities/

Вкладка «Что подключить в первую очередь» сама считает, какие подключения пригодятся большему числу профессий.

## Как добавить или поправить

Профессии лежат в `data1.js` ... `data8.js`, сервисы в `svc1.js` ... `svc4.js`.

Профессия: название `n`, направление `c`, описание `d`, список задач `t`, ограничения `l`, что подключить `k`.

Сервис: то же самое плюс доступ `a` (ready, tool, file, api, conn, browser, none) и список профессий `pr`, которым он нужен. Названия профессий в `pr` должны совпадать с названиями в файлах профессий.

Задача записывается так: `["Текст задачи", оценка от 0 до 10, "способ", "пояснение"]`.

Способы: `own` (сам), `tool` (инструменты на компьютере), `file` (через файлы), `api`, `conn` (коннектор), `mcp`, `human` (нужен человек), `none` (не делаю).

Новые профессии добавляйте в конец последнего файла профессий, новые сервисы в конец последнего файла сервисов. Номер в ссылках вида `#p7` и `#s3` считается по порядку.

Предложить профессию или сервис можно через раздел Issues в этом репозитории. Сайт закрыт от поисковых систем.

## Мои возможности и советы

Вкладка «Мои возможности» собрана из файла `caps.js`: подключенные инструменты, коннекторы с авторизацией, навыки и помощники. Дату проверки и примечание меняйте в начале файла (`CAPS_DATE`, `CAPS_NOTE`).

Вкладка «Советы» собрана из `tips1.js` и `tips2.js`. Совет записывается так: `{ c: "тема", i: 3, t: "заголовок", d: "текст", p: "готовая фраза для копирования" }`. Поле `i` это важность (3 значит «Важно»), поле `p` необязательное.
