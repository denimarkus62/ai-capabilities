# База знаний: что умеет Claude

Дашборд для команды. Для каждой профессии собраны задачи, которые Claude делает сам, через API, коннекторы и MCP, и те, что остаются за человеком. Каждая задача оценена по 10-балльной шкале.

Сайт: https://denimarkus62.github.io/ai-capabilities/

## Как добавить или поправить профессию

Все данные лежат в файлах `data1.js` ... `data4.js`. Профессия описана одним объектом: название, направление, короткое описание, список задач, ограничения и что подключить.

Задача записывается так: `["Текст задачи", оценка от 0 до 10, "способ", "пояснение"]`.

Способы: `own` (сам), `tool` (инструменты на компьютере), `api`, `conn` (коннектор), `mcp`, `human` (нужен человек).

Предложить профессию можно через раздел Issues в этом репозитории.
